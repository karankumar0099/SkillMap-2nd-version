Background

Problem & Solution

❌ The Problem

  • 😵 Students don't know where to start learning a new skill
  • 🔄 Too many tutorials online — leads to confusion
  • ⏳ Time is wasted on wrong or random topics
  • 📉 No way to track progress — students lose motivation
  • ❓ No one to answer doubts instantly while learning

✅ Our Solution — SkillMap AI

  • 🗺️ Gives a clear step-by-step roadmap for any skill
  • 🤖 Built-in AI Tutor answers any doubt instantly
  • 📝 AI Quizzes test your knowledge after each topic
  • 📊 Dashboard shows your learning progress
  • 🌙 Modern UI with Dark/Light theme

Features

Key Features — Part 1

🗺️

Interactive Learning Roadmaps

Pre-built roadmaps for Frontend, Backend, React, Python, Node.js, Full Stack and more. Each roadmap has clear steps — click any step to see its description, key topics, and learning resources.

🤖

AI Tutor (Chatbot)

Powered by Groq API + LLaMA 3.1. Ask any question like "What should I learn first?" or "Explain React hooks" — the AI replies instantly in formatted text with headings, code blocks, and lists.

📝

AI-Powered Quiz System

Every roadmap topic has a "Take Quiz" button. The AI generates 4 unique questions for that topic. If AI is unavailable, pre-built questions are used as fallback. Shows score with visual progress.

📊

Progress Dashboard

After login, users see a personal dashboard showing total steps completed, overall progress %, and per-roadmap progress bars. Helps track learning journey across multiple skills.

Features

Key Features — Part 2

🔐

User Authentication

Secure Login & Signup system. Passwords are hashed using bcrypt. Login sessions use JWT tokens (valid 30 days). User progress is saved in the database automatically.

🌓

Dark & Light Theme

Users can switch between dark mode and light mode anytime. Theme preference is saved in browser's localStorage — stays even after closing the browser.

📇

Portfolio Page

A built-in personal portfolio page showcasing the developer's profile, skills, work experience, projects, and a download resume button. Built with clean, modern design.

📬

Contact Page

Users can send feedback or messages through a contact form. The data is saved in MongoDB for later review. Form includes name, email, and message fields.

📋 Detailed Steps

  • 1️⃣Home Page — User sees hero section with "Start Skill Map" button and scrolling popular skills
  • 2️⃣Skill Input — User enters the skill name, skill level (Beginner/Intermediate), and clicks Submit
  • 3️⃣Roadmap View — The matching roadmap is shown as connected nodes. Each node can be expanded.
  • 4️⃣Learn & Quiz — User reads topics, clicks "Take Quiz" — AI generates 4 questions instantly
  • 5️⃣Mark Complete — Checkbox on each step saves progress to MongoDB (must be logged in)
  • 6️⃣Dashboard — Shows overall progress bars, total steps completed, and active roadmaps
